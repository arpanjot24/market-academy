# Market Academy

A free, offline-capable Progressive Web App that teaches the Indian stock market, from beginner to advanced.

**Open it:** https://arpanjot24.github.io/market-academy/ (on Android Chrome, use "Install app" / "Add to Home screen").

Phase 1: lessons (market basics, economics, financial terms), a 20-term glossary, quizzes, spaced revision, progress tracking, and JSON backup. Built with React, TypeScript, Vite, Tailwind CSS and vite-plugin-pwa. Progress is stored only on your device (IndexedDB).

Educational content only — not investment advice.

## Develop
```
npm install
npm run dev
npm run build
```
